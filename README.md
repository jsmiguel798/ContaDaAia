# Projeto de PI — O Conto da Aia
Este projeto consiste em um site em HTML com o objetivo de apresentar uma análise da obra O Conto da Aia, de Margaret Atwood, abordando seus principais aspectos literários e sociais.
O site foi criado como trabalho acadêmico da disciplina de Português, com foco na organização de conteúdo informativo em formato de página web.
## Tema abordado
A página apresenta uma análise da obra, destacando:
- Contexto histórico e social da narrativa
- Personagens principais e seus papéis na sociedade de Gilead
- Críticas sociais presentes na obra
- Importância da obra na literatura contemporânea
## Tecnologias utilizadas
O projeto foi desenvolvido utilizando tecnologias básicas da web:
- HTML5 – Estrutura do site
- CSS3 – Estilização visual
- GitHub Pages – Hospedagem do site
